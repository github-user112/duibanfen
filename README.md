# 对半分 · 参赛工程

小米浏览器 Vibe Coding 大赛参赛作品。**同屏双人对抗的打砖块式弹球（Pong）**：一部手机平放桌面，两人各守屏幕一端，把球打过对方底线。纯前端静态资源，无外链、无 SDK、无账号、无联网请求。

## 玩法

- **两个人，一台手机**：屏幕上下各一块挡板，手指在各自半屏左右滑动即可控板，多点触控按 `pointerId` 分配归属，互不抢手。
- **先到 7 分**：球出界即对手得分，每分后从中央自动发球。
- **越拉越快**：对拉第 5 / 10 / 15 / 20 拍各提速一档，长回合会越来越难接。
- **单人也能玩**：只有一个人时，上方挡板交给 AI，你守下方。
- **桌面端补键盘**：`←` `→` 控下方，`A` `D` 控上方，方便在电脑上双人试玩。

## 本地运行

```bash
cd duibanfen
python -m http.server 8123 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8123/
```

直接双击 `index.html` 也能跑，起本地服务是为了模拟真机的相对路径与缓存行为。

## 技术要点

- **Canvas 2D 手绘**，无任何框架、无外部字体/CDN，单文件逻辑自洽。
- **固定步长积分** 1/120s，渲染与物理解耦，低帧率下走向依然稳定；页面不可见时自动暂停，回来不跳球。
- **扫掠式挡板碰撞**：用上一帧 `prevY` 判断是否跨过挡板平面，避免高速球在一帧内穿透球拍。
- **按实测尺寸布局**：画布宽高由容器测出后按比例推算板长、球半径、初速与上限，横屏宽屏（≥760px）切左侧信息栏布局。
- **WebAudio 现场合成音效**，不加载任何音频文件；首次触摸时才创建 `AudioContext`，符合移动端自动播放限制。
- 视觉：深底 `#0d1116`，上方青色 `#45d9c8`、下方橙色 `#ff7a5c`，得分带粒子与拖影反馈。
